# SQLD Study Notes

SQLD 학습 내용을 GitHub에서 보기 좋도록 주제별로 분류한 정리 노트입니다.

> 이 문서는 기존에 정리한 내용을 **분류하고 Markdown 형식으로 정돈한 버전**입니다.  
> 개념 검증이나 오답 교정이 목적이 아니며, `SQL 최적화 기본 원리`까지 보완하여 전체 학습 내용을 정리했습니다.

## 📚 구성

## 전체 학습 흐름

```text
1. 데이터 모델링
   ├─ 데이터 모델의 이해
   ├─ 엔터티 / 속성 / 관계 / 식별자
   └─ 성능 데이터 모델링
      ├─ 정규화 / 반정규화
      ├─ 대량 데이터 처리
      ├─ DB 구조와 성능
      └─ 분산 데이터베이스

2. SQL 기본
   ├─ 관계형 데이터베이스
   ├─ DDL / DML / TCL
   ├─ WHERE / 함수
   ├─ GROUP BY / HAVING
   ├─ ORDER BY
   └─ JOIN

3. SQL 활용
   ├─ 표준 JOIN
   ├─ 집합 연산자
   ├─ 계층형 질의 / 셀프 조인
   ├─ 서브쿼리
   ├─ 그룹 함수
   ├─ 윈도우 함수
   ├─ DCL
   └─ 절차형 SQL

4. SQL 최적화 기본 원리
   ├─ 옵티마이저와 실행계획
   ├─ 인덱스 기본
   └─ 조인 수행 원리
```
